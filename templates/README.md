# Templates

Copy-ready, generic templates for every Megamind artifact. Placeholders use
`<angle brackets>`. The authoritative schema description lives in
[docs/schemas.md](../docs/schemas.md).

| File | Purpose |
| --- | --- |
| `registry.json` | `.megamind/registry.json` shape with all fields |
| `routing-card.md` | Per-wiki routing card (`CARD.md`) |
| `digest.md` | Per-wiki digest (`DIGEST.md`) |
| `index.md` | Per-wiki domain index (`INDEX.md`) |
| `topic-page.md` | A single knowledge page |
| `micro-wiki-index.md` | Index for a promoted micro-wiki folder |
| `proposal.md` | Captured proposal (normally written by `megamind-axi capture`) |
| `top-level-wiki-proposal.md` | Human-approval request for a new top-level wiki |
